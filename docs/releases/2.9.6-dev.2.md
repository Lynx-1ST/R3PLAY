# R3PLAYX 2.9.6-dev.2

- Fix Last.fm authorization rejecting valid tokens containing punctuation. Verified token retrieval against the live service in packaged Electron.
- Default audio cache to `audio_cache` beside the executable. Automatically use the original user-data directory if the preferred folder is not writable. Users can choose another folder in settings; the choice is saved across restarts. Existing files in previous locations remain untouched.
- Hide scrollbars in settings dropdowns while preserving keyboard and wheel scrolling.
- Remove redundant settings descriptions and shorten essential notes.
- Align startup colors, toggles and legacy brand utilities with the selected accent color.

Install over the previous build without uninstalling. Application credentials remain required for Last.fm; GitHub release builds use repository Actions secrets.
