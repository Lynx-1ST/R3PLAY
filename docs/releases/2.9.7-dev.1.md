# R3PLAYX 2.9.7-dev.1 — Last.fm explorer

Local development preview of the expanded Last.fm integration.

- Dedicated Last.fm navigation with public profile lookup, lifetime listening counts and top tracks, artists and albums across six time periods.
- Paginated recent scrobbles and loved tracks, including Now Playing and listening timestamps.
- Personal discovery seeded from top artists/tracks, global music charts and genre/tag browsing.
- Artist biographies, popular tracks, song details, tags and similar music; the currently playing song can be used as a discovery seed.
- Explicit Last.fm love/unlove actions for the authenticated account, independently of NetEase favorites.
- Playback resolves Last.fm metadata to the app's music catalog. Ambiguous results open search for the user to choose a recording. Later playback requests take precedence over slower earlier searches.
- Paced, deduplicated and bounded API reads, cache invalidation on account changes/writes, rate-limit backoff and safe metadata normalization.
- Empty/error/retry states, browser-history navigation, readable controls in light/dark themes and responsive layouts.

Read access and public discovery work without signing in when this build is configured. Loving tracks and scrobbling require Last.fm authorization. Last.fm provides metadata, not audio streams.

Validation includes desktop/web unit suites, both TypeScript checks, 15 live Last.fm read methods, browser interaction/layout checks and packaged desktop checks with public data. Authentication writes are verified with fixtures; no user's Last.fm library is changed by the tests.
