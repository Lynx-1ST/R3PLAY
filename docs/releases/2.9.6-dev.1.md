# R3PLAYX 2.9.6-dev.1

Development build for testing the next version.

- Add automatic crossfade in Settings → Experiments, with a selectable duration of 1–12 seconds. Disabled by default.
- Add audio cache limits, least recently used eviction, folder selection and cleanup in Settings → Storage.
- Virtualize large album/artist lists and reduce playlist rendering overscan.
- Pause visual audio updates and CSS animations when the app is minimized, while keeping music playing.
- Add Settings → Diagnostics with memory, uptime, recent errors and a redacted JSON export.
- Add Last.fm browser authorization, Now Playing, scrobbling and persistent offline retries in Settings → Player.

Last.fm requires the application's `LASTFM_API_KEY` and `LASTFM_API_SECRET` before building. GitHub builds read these from repository Actions secrets. An unconfigured build leaves Last.fm login disabled.

Validation: 642 desktop tests and 137 web tests passed, along with both TypeScript checks. Packaged Electron tests verified real HTML audio overlap and cleanup, continued music while minimized, diagnostics export, a 10,000-song playlist and a 1,000-song album. Actual Last.fm account authorization requires application credentials and the user's grant.

Install over the existing version; uninstalling is unnecessary. Retain the previous stable installer for rollback.
