# R3PLAYX v2.9.4

Hotfix for track favorites and playlist subscriptions.

- Fixed liking/unliking tracks sending the wrong operation after optimistic cache changes.
- Liked Songs contents and counts refresh after a successful favorite change.
- Track context menus offer Remove from Liked Tracks for songs already liked.
- Fixed subscribing/unsubscribing Browse playlists and refreshing the My Music library.
- Uses consistent profile user IDs, serializes favorite mutations and preserves state on server failure.
- Adds five mutation regression tests; all 102 web tests and web typecheck passed locally.
- Browser verification used mocked APIs for removal, subscription, library appearance and unsubscription.

The Windows pipeline performs full tests, builds, packaging and packaged startup/runtime probes.
This release retains the v2.9.3 context-menu fixes and v2.9.2 streaming audio cache and My Music improvements.

## Known limitations

The Windows installer is unsigned. Real-CDN streaming validation remains partial: a small Kuwo MP3
transfer/cache/Range probe passed, while full NetEase 320K, Lossless, Hi-Res, AAC and audio-effect
cases remain unverified with authorized URLs. Caching failure never interrupts playback.

Back up your profile before upgrading. Downgrading to v2.9.1 requires restoring the backup or,
with the app stopped, resetting only AudioVariant following docs/audio-cache-v2.9.md because
v2.9.2+ adds its hash column and streaming filenames. Retain account, playlist and settings tables.
