# R3PLAYX 2.9.7

- Explore Last.fm listening statistics, recent plays, loved tracks, top artists/albums, charts, tags and personalized discovery.
- Resolve missing artwork from matching catalog entries, with persistent bounded caching and cancellation when leaving a page.
- Reduce idle IPC, status polling and visual work. Share queue metadata across reordered lists and bound large request bursts without changing playback quality.
- Preserve signed audio URLs during playback and crossfade.
- Reject invalid playback IDs before cache or provider access.
- Cache and replay YouTube WebM/Opus audio with the correct file extension, MIME type and byte ranges.
- Correct standalone server migration ordering, version boundaries and rollback after a failed migration.
- Diagnostics now reports working-set RAM by Main, Renderer, GPU, Utility and Other, with per-process PID and private memory where available.

## Windows release

Built and smoke-tested by the standard Windows GitHub Actions workflow. `release-provenance.json` records the commit, workflow run and SHA-256 of the installer and updater assets.

Working-set totals may include shared pages and do not represent unique physical RAM or JavaScript heap size. Audio bitrate, image resolution and foreground effects are preserved.
