# R3PLAYX 2.9.0

Windows stability, security and release reliability update.

- Fix large-playlist track fetching without changing caller parameters or track order.
- Validate positive safe track IDs and parameterize bulk cache database queries.
- Remove an unreachable artist-cache branch after reviewing its callers.
- Restrict Electron navigation to the app origin and validate external GitHub links.
- Validate renderer identity and main-frame ownership centrally for exposed IPC handlers.
- Update Electron to 43.5.0 and patch Fastify, Axios and networking dependencies.
- Run full Windows checks on dev and release; verify packaged runtime and application startup.
- Separate manual development prereleases from tagged stable releases, sharing the same Windows validation pipeline.
- Remove obsolete cross-platform build workflow and root npm lockfile while preserving the packaged runtime's npm lock.

Audio quality, variants and byte-range playback remain unchanged. The proposed
streaming audio-cache redesign has not been implemented in this release.

Known limitations: dependency audits still contain unresolved advisories, including
node-forge without an available patch. Local Windows packaging is unsigned.
