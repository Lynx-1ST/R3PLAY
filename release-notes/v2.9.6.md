# R3PLAYX v2.9.6

- Last.fm sign-in, Now Playing and scrobbling, with encrypted sessions and an offline retry queue. Pausing and seeking do not count toward listening time.
- Optional crossfade in Settings → Lab, with a duration from 1 to 12 seconds.
- Lower background activity while the app is hidden, and lighter rendering for large music lists.
- Audio cache limits, cleanup and a customizable folder. The default cache sits beside the installed app, with a writable AppData fallback when access is blocked.
- Diagnostics with recent errors, a redacted report export and a Clear logs button.
- Cleaner settings descriptions and hidden dropdown scrollbars, with keyboard scrolling preserved.
- Consistent accent colors for the default theme and saved color preferences.
- Fixes playlist names being clipped in Browse when resizing the window.
- Correctly accepts Last.fm authorization tokens containing punctuation and handles cache folder permission errors.

This is the official stable Windows x64 release. Install over your current version without uninstalling to preserve settings.
