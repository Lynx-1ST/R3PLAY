# R3PLAYX v2.9.5

- New mint R/Play logo, desktop and tray icons, web favicon and PWA icons.
- Self-hosted Manrope typography throughout the interface, with Vietnamese support.
- Opening logo reveal with a subtle glow and a single light sweep. The intro waits
  until the desktop window is visible; reduced motion omits scaling and the sweep.
- Settings → Lab → Startup animation enables or disables the intro on the next
  launch. The preference is saved; existing profiles default to enabled.
- Clears legacy PWA workers and their caches before loading the desktop UI, so
  upgrades display the packaged interface. Cookies, local storage and IndexedDB
  are preserved.
- Corrects macOS and Linux packaging icon paths.

The Windows pipeline verifies tests, builds, packaging and packaged startup/runtime
probes. This development prerelease does not replace the stable release.
