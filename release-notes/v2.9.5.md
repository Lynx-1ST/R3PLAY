# R3PLAYX v2.9.5

- New mint R/Play logo, desktop and tray icons, web favicon and PWA icons.
- Self-hosted Manrope typography throughout the interface, with Vietnamese support.
- Opening logo reveal with a subtle glow and a single light sweep. The intro waits
  until the desktop window is visible; reduced motion omits scaling and the sweep.
- Settings → Lab → Startup animation enables or disables the intro on the next
  launch. The preference is saved; existing profiles default to enabled.
- Clears legacy PWA workers and their caches before loading the desktop UI, so
  upgrades display the packaged interface. Cookies, local storage and IndexedDB
  are preserved.
- Corrects macOS and Linux packaging icon paths.
- Waits for the packaged runtime and SQLite files to finish installing before
  loading the application, preventing missing-module errors during updates.
- Uses graceful shutdown and flushes browser storage before quitting. Restores
  settings from Electron's saved copy when renderer storage is missing or damaged.
- Preserves user data by default when uninstalling the new version.
- Includes the development improvements to offline logout, daily check-in,
  paginated search, retry actions, keyboard playback and stable/dev updates.

The Windows pipeline verifies tests, builds, packaging and packaged startup/runtime
probes. This is the official stable Windows x64 release.

If an older build fails to start after updating, close the app and install this
version over the existing installation without uninstalling first. Previously
deleted settings can only be recovered if a saved copy still exists.
