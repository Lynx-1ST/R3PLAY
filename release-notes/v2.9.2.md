# R3PLAYX v2.9.2 development

Audio Cache Streaming v2 moves caching downloads out of the renderer into background
Electron jobs. Playback starts independently and continues when caching fails.

- Streams remote audio to disk with incremental SHA-256 and disk metadata parsing.
- Bounds concurrency/queue, file size, timeouts and redirects; validates each CDN/DNS hop.
- Preserves track, quality, source, format, bitrate, sample rate, bit depth, hash and filename.
- Keeps Lossless, Hi-Res and effect variants separate; rejects unproven quality.
- Atomically finalizes files, preserves old cache on failure, cancels jobs and recovers orphan files.
- Retains cached Range/HEAD playback and legacy cache compatibility.
- Includes standalone Unblock contract, empty DB query and context-menu identity fixes.

See `docs/audio-cache-v2.9.md` for limits, tests, benchmark and rollout/rollback details.
This is development work; stable remains v2.9.1.
