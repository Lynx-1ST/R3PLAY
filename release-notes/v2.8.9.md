## R3PLAYX v2.8.9 — Audio Modes and Download Quality

### Audio modes
- Added a compact audio mode selector to the miniplayer: **Off**, **Spatial Audio**, **Audio Vivid**, and **Surround Audio**.
- Apply mode changes to the current track while preserving the playback position and playing/paused state.
- Check availability for the current track and account through the NetEase API. Unsupported or unverified modes appear dimmed; clicking them shows a notification. No status notes are displayed beneath individual options.
- Keep Spatial Audio, Audio Vivid, and Surround Audio untranslated in the Vietnamese interface, and use Lossless for lossless quality.
- Keep the menu compact and within the viewport, including when the miniplayer is collapsed.

### Downloads
- The download button now opens a selector with **eight NetEase quality levels**: Spatial Audio, Audio Vivid, Surround Audio, Master, Hi-Res, Lossless, HQ (320 kbps), and Standard (128 kbps).
- Use the dedicated `/song/download/url/v1` API to check download access separately from playback access.
- Check each quality when opening the selector and recheck when selecting/downloading. If the selected quality is unavailable, do not silently download a lower quality, a preview, or audio from an alternative provider.
- Preserve the file format returned by the API instead of always using an MP3 extension.
- Include the Surround download parameters and Android client configuration required by API Enhanced for Audio Vivid.

### Fixes and reliability
- **Fixed the startup failure in the previous test installer:** removed duplicate registration of the download route that prevented the internal server from starting.
- Fixed returning to regular quality when turning audio modes off; allow regular playback fallback when an enhanced source fails.
- Store separate cached audio variants with quality, format, and metadata to avoid reusing the wrong file after changing quality.
- Fixed byte-range streaming, same-origin cached audio URLs, and metadata for cached alternative sources.
- Fixed logging in the sandboxed preload and included required runtime dependencies.

### Validation
- Web and desktop TypeScript checks, plus tests for audio modes, download access, listening sessions, and audio output.
- Cache, byte-range, and media CORS tests.
- Packaged runtime dependency checks and EXE startup tests using an isolated profile, covering SQLite initialization, the web interface, and the download route.

### Availability
Playback and download availability depend on the NetEase account's permissions and the audio versions available for each track. Not every track offers all eight quality levels, and multichannel playback depends on the output device. Downloads at every premium level have not been verified with a VIP/SVIP account during this validation session.

### Installation
Download **R3PLAYX-2.8.9-win-x64-Setup.exe** from Assets below and install it over your current version. If the previous test build is still running in the background, end R3PLAYX in Task Manager before installing. Uninstalling or deleting application data is unnecessary.
