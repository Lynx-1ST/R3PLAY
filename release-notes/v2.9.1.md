# R3PLAYX 2.9.1

My Music usability and cache reliability fixes for Windows.

- Fix context menus that remained open. Click outside or press Escape to close them; menus can be reopened normally.
- Refresh the My Music layout with compact artist cards and accessible controls.
- Show login, loading, empty and retry states in the personal library.
- Switch to an available library tab when NetEase playlists are hidden.
- Identify the favorites playlist by its metadata rather than its position in the response.
- Update library labels in English, Vietnamese and Simplified Chinese.
- Keep audio-source caller parameters and pending query keys stable when provider cookies change.
- Handle empty bulk database writes without preparing SQL, preserving nonempty transaction behavior.
- Allow external GitHub navigation only over HTTPS.
- Share positive safe integer ID validation across desktop and server cache reads and writes.
- Correct README badges, release-channel descriptions and download links.

Validation: 75 web tests and 538 desktop/cache/server tests, TypeScript checks for all three packages, and web, Electron main and server builds. Menu dismissal and library states were also verified in Chromium with isolated test data.

Known limitations: Windows packaging is unsigned. Existing dependency advisories and pre-existing lint errors remain; this patch does not update dependencies.
